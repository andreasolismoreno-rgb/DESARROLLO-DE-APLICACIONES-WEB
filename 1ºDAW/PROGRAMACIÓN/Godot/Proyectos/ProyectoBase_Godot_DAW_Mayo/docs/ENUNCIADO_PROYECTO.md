# Encargo de proyecto

Sois un pequeño equipo de desarrollo. El cliente os pide un minijuego 2D funcional y sencillo.

## Requisitos mínimos

- El jugador se puede mover.
- Hay objetos recogibles.
- Hay una condición de final de partida.
- Se muestra información en pantalla.
- Al finalizar, se genera un JSON con los datos de la partida.
- El código está organizado en varios scripts.
- El equipo puede explicar qué hace cada script.

## Ampliaciones posibles

- Añadir enemigos.
- Añadir vidas.
- Añadir tiempo máximo.
- Añadir varios niveles.
- Añadir más tipos de objetos.
- Añadir una pantalla inicial.
- Añadir sonidos.
- Añadir conexión posterior con Java y MySQL.
