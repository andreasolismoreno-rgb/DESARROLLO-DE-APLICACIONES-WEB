Este directorio solo contiene una clase inicial para continuar el proyecto en Java.

Siguiente paso recomendado:
1. Crear ConexionBD.java
2. Crear JugadorDAO.java
3. Crear PartidaDAO.java
4. Leer partida.json
5. Insertar jugador y partida en MySQL

Para leer JSON en Java puedes usar una librería como Gson o Jackson, o hacerlo de forma simplificada si el profesor lo proporciona.
